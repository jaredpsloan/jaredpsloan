# CLAUDE.md

Guidance for Claude Code (or any agent) working in this repo.

## What this is

Jared Sloan's GitHub profile repo: a Career section in `README.md`, an
auto-generated index of his active repos, and `website/` — the source and
AWS deploy tooling for jaredsloan.com, a live single-page professional
site.

## Structure

- `README.md` — Career summary (role, background, certification path) and
  the auto-generated repo index (`<!-- REPO-INDEX:START -->` block,
  regenerated by `scripts/generate-index.sh` via
  `.github/workflows/update-index.yml` — don't hand-edit that block, it
  will be overwritten).
- `website/index.html` — complete, self-contained static site (fonts
  inlined as base64 `@font-face`, no build step, no external requests).
  Content is derived from the Career section in `README.md` — if one
  changes, check whether the other needs to as well.
- `website/01-aws-website-setup.ps1` — idempotent PowerShell deploy
  script (S3 + CloudFront + ACM + Route53). Safe to re-run; it picks up
  wherever the last run left off. To push a content update after editing
  `index.html`:
  ```powershell
  aws s3 cp website/index.html s3://jaredsloan.com/index.html --content-type text/html --profile default
  aws cloudfront create-invalidation --distribution-id <ID> --paths '/*' --profile default
  ```
- `website/README.md` — full deploy history and rationale.
- `.github/workflows/deploy-pages.yml` — still auto-deploys the same site
  to GitHub Pages (`jaredpsloan.github.io/jaredpsloan`) on every push;
  harmless leftover from before the AWS deploy went live, not the primary
  URL.
- `scripts/` — the repo-index generator.

## Working conventions

- **AWS credentials**: the `default` profile (IAM user `jaredpsloan-admin`,
  broad `AdministratorAccess`) is the standing local credential for this
  account's personal-site deploys — same one used for
  [packetpupper](https://github.com/jaredpsloan/packetpupper)'s site. For
  syncing this credential to another machine, use the Bitwarden pattern in
  [mineral-saga/infrastructure/bitwarden/](https://github.com/jaredpsloan/mineral-saga/blob/main/infrastructure/bitwarden/README.md)
  rather than copying files by hand.
- **Secrets**: never committed. `INDEX_PAT` (a fine-grained GitHub PAT for
  the repo-index workflow) lives as a repo secret, not in any file here.
- **Repo-context convention** (documented in `README.md`): every active
  repo in this account starts its README with a `**Status:** ...` line —
  keep this repo's own README and `website/README.md` in sync with
  reality (this is the repo that got caught with a stale "not yet
  deployed" status once already — check before assuming an old doc is
  still accurate).
- No PR workflow, single branch (`master`), personal repo — commit/push
  freely as normal.
